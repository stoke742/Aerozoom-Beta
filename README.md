<a id="overview"></a>

**AeroZoom Beta** is a free utility designed for Windows that enhances the standard Windows Magnifier with advanced zooming capabilities. This latest version provides users with a seamless experience, allowing for full-screen magnification through intuitive mouse-wheeling and pinch-to-zoom gestures. Perfect for presentations and home-theater setups, AeroZoom integrates effortlessly with Sysinternals ZoomIt to provide additional functionality.
